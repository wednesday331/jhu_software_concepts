Module 1 - Personal Portfolio Website
Shrey Shanbhag

DESCRIPTION

This project is a personal portfolio website developed using Python,
Flask, HTML, and CSS. The website includes a homepage with a biography
and profile picture, a contact page, and a projects page.

The application uses Flask for routing, HTML templates for the web pages,
and CSS for styling.


REQUIREMENTS

- Python 3.10 or later
- Flask
- Other required Python packages are listed in requirements.txt


INSTALLATION

1. Open a terminal or PowerShell.

2. Navigate to the module_1 directory.

Example:

cd C:\Users\wedne\jhu_software_concepts\module_1

3. Install the required Python packages:

pip install -r requirements.txt


RUNNING THE WEBSITE

1. From inside the module_1 directory, run:

python run.py

2. Open a web browser and navigate to:

http://localhost:8080

3. Use the navigation bar to access the Home, Contact, and Projects pages.


STOPPING THE APPLICATION

Return to the terminal where the Flask application is running and press:

Ctrl + C
