GradCafe Analytics Documentation
================================

GradCafe Analytics is a Flask-based application for collecting,
cleaning, storing, and analyzing graduate admissions data.

The Module 4 version includes automated testing, database dependency
injection, continuous integration through GitHub Actions, and
Sphinx-generated source documentation.

Project Features
----------------

* GradCafe data collection and scraping
* PostgreSQL database storage using SQLAlchemy
* Flask-based analytics webpage
* LLM-assisted program and university standardization
* Automated Pytest test suite
* 100 percent source-code test coverage
* GitHub Actions continuous integration
